Every item on the 24-July Admin & Agent list has been worked through — the six core time/status bugs plus all nine dashboard/agent items. The headline problem (Active time running double, totals not tallying, a 16-hour break on the board) came from one root cause, fixed at the source. This revision also covers the four follow-ups you asked me to continue with: the meeting reminder popup, password-protected uninstall, and self-service diagnostics for biometric sync and screenshot evidence.

The one root cause behind the time bugs. The agent's sync engine (sync.drain()) had no re-entrancy guard. It is triggered from many places and a 15-second timer, and waits on the network for each event — so two runs overlapped, both read the same queued batch, and both sent it. The server stored every Active/Idle stretch twice. That is why Active climbed ~2× and Active+Idle+Break never added up. It was never a clock problem.
