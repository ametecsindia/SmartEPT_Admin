Bugs fixed

EPT25-09Roles → permission matrix now savesFixedP1
Root cause The Save handler ran $$(…).filter().map(), but $$ returns a NodeList (no .filter/.map) — it threw before the try/catch, so the save died silently with no error.
Fix Wrapped in Array.from(...). The matrix now persists for every role (system + custom). 302fec8
EPT25-08Meetings no longer auto-complete at scheduled endFixedP1
Root cause CloseMeetings flipped meetings to COMPLETED at the scheduled end, so overrunning meetings showed wrong live status and could never be ended.
Fix Removed auto-complete. A meeting past its end stays IN_PROGRESS (overrunning) until someone Ends it; a long-stop auto-closes anything nobody ended 4h past schedule (AUTO_CLOSED if it had attendance, NO_SHOW if nobody joined). Live status now reflects reality. a56c993
EPT25-10"End meeting" no longer errorsFixedP1
Root cause Because the meeting was already auto-marked COMPLETED (EPT25-08), end() aborted with "this meeting is already over."
Fix With auto-complete gone, End works. It records the actual end time + who ended it, and closes all sessions and the live "In Meeting" state at once. End is now allowed for the organizer + company/branch admin + super-admin + HR admin (per your decision). a56c993
EPT25-01Late minutes honour the Policy-tab graceFixedP1
Root cause The Policy-tab "Late grace (min)" was saved but never read — the late calc used the shift's grace only, so your 10-min setting had no effect.
Fix The derivation now resolves the effective Attendance policy and uses its late_grace_minutes, falling back to shift grace when none is assigned. (Needs a shift start time to compute — see run-steps.) 302fec8
EPT25-02Employee-archive ZIP download worksFixedP2
Root cause A Laravel 11 change moved the local disk root to storage/app/private, but the ZIP was written to storage/app/archives. So the row went READY yet the download looked in the wrong place → "file could not be found."
Fix The build now writes through the disk, and download has a legacy fallback so archives built before the fix still download. Clearer error if a build genuinely isn't ready. 2ec0087
EPT25-03Violations "Export CSV" returns rowsFixedP2
Root cause The export ran whereBetween('started_at',[today,today]) on a datetime column — a bare date upper bound is 00:00:00, so every same-day event was excluded and the file came back header-only.
Fix Inclusive whole-day boundaries (00:00:00 … 23:59:59). Same-day exports now contain that day's violations. 2ec0087
EPT25-11Organizer no longer shown "Absent"FixedP2
Root cause The organizer runs the meeting from the console (no agent join), so the participation report had no session for them and marked them Absent.
Fix The report now recognises the organizer (via their linked employee) and shows them as ORGANIZER (present) rather than Absent. a56c993
EPT25-04Honest evidence message (capture-failed vs purged)FixedP2
Root cause Any missing screenshot was blamed on "data-retention policy," even when the real cause was an upload/storage failure on the device (captured but never stored).
Fix Three distinct cases now — Screenshot not stored (capture failed on device, points to Troubleshooting), Evidence no longer available (genuinely purged by retention), and No screenshot captured. 2ec0087
